# GlutenFreeMap list template

This repository is a template for a [GlutenFreeMap](https://glutenfreemap.org) list. If you whish to manage your own public or private list on GlutenFreeMap, you may clone this repository to get started, then use the [GlutenFreeMap](https://glutenfreemap.org) app to manage your list.

If you reached this page while creating a new repository from GlutenFreeMap, you may close this tab to return to the GlutenFreeMap app.
